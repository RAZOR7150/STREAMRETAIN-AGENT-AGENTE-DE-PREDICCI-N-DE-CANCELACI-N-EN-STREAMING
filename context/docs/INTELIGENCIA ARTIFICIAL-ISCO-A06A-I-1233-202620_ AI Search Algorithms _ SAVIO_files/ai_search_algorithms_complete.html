Uninformed Search

Blind search — no domain knowledge beyond the problem definition

7
algorithms
01
DFS — Depth-First Search
›
📥 Input
Initial state, goal test, successor function, action set
⚙️ Process (Actions)
Expand the deepest unexpanded node using a LIFO stack. Recursively explore each branch to maximum depth before backtracking. No duplicate detection unless cycle checking is added.
📤 Output (Result)
A path from initial state to goal (if found), or failure. Path may not be optimal.
💾 State
Stores only the current path from root to frontier node. States on the current path are kept in memory.
💰 Path Cost
Does NOT minimize path cost. Returns first solution found. Time: O(b^m), Space: O(bm).
Complete*Not OptimalSpace O(bm)LIFO Stack
02
BFS — Breadth-First Search
›
📥 Input
Initial state, goal test, successor function, action set
⚙️ Process (Actions)
Expand the shallowest unexpanded node using a FIFO queue. Explore all nodes at depth d before d+1. Uses visited set to avoid revisiting states.
📤 Output (Result)
The shallowest solution path (minimum steps). Returns failure if goal is unreachable.
💾 State
Stores all generated nodes at current and previous frontiers. Exponential memory usage.
💰 Path Cost
Optimal when all step costs are equal (unit cost). Time: O(b^s), Space: O(b^s).
CompleteOptimal (unit cost)Space O(b^s)FIFO Queue
03
UCS — Uniform Cost Search
›
📥 Input
Initial state, goal test, successor function, non-negative step costs
⚙️ Process (Actions)
Expand the node with lowest accumulated path cost g(n). Uses a priority queue ordered by g(n). Equivalent to Dijkstra's algorithm on graphs.
📤 Output (Result)
The least-cost solution path. Guarantees optimality for non-negative step costs.
💾 State
Stores all generated nodes with their cumulative costs. Priority queue maintained by cost.
💰 Path Cost
Optimal for any non-negative step costs. Time: O(b^(C*/ε)), Space: O(b^(C*/ε)).
CompleteOptimalPriority QueueNon-neg. costs
04
IDS / IDDFS — Iterative Deepening Depth-First Search
›
📥 Input
Initial state, goal test, successor function, action set
⚙️ Process (Actions)
Run DFS with depth limit l=0,1,2,… until goal is found. At each limit, perform complete depth-limited DFS. Nodes at depth d are regenerated O(b) times.
📤 Output (Result)
The shallowest solution (same as BFS) using only O(bd) memory.
💾 State
At any iteration, only stores the current path (like DFS). Memory is O(bd) at depth d.
💰 Path Cost
Optimal when step costs are uniform. Time: O(b^d), Space: O(bd).
CompleteOptimal (unit cost)Space O(bd)Best uninformed
05
DLS — Depth-Limited Search
›
📥 Input
Initial state, goal test, successor function, depth limit l
⚙️ Process (Actions)
Execute DFS but cut off expansion at depth limit l. Return "cutoff" if limit hit; "failure" if all nodes explored.
📤 Output (Result)
A solution path at depth ≤ l, or "cutoff"/"failure" status.
💾 State
Stores current path up to depth l. Space O(bl).
💰 Path Cost
Not optimal. Time: O(b^l), Space: O(bl). Incomplete if l < d.
Incomplete if lNot OptimalSpace O(bl)Depth-bounded
06
Bidirectional BFS — Bidirectional Breadth-First Search
›
📥 Input
Initial state, goal state, bidirectional successor functions
⚙️ Process (Actions)
Run two simultaneous BFS from start and goal. Alternate expanding frontiers. Stop when frontiers intersect.
📤 Output (Result)
The shortest path connecting start and goal through the meeting node.
💾 State
Two frontier sets and two visited sets maintained simultaneously.
💰 Path Cost
Optimal for unit costs. Time: O(b^(d/2)), Space: O(b^(d/2)). Requires explicit goal state.
CompleteOptimal (unit cost)Space O(b^(d/2))Requires goal state
07
Bidirectional UCS — Bidirectional Uniform Cost Search
›
📥 Input
Initial state, goal state, bidirectional successor functions, non-negative costs
⚙️ Process (Actions)
Two simultaneous UCS with priority queues in both directions. Stop when combined cost beats best known solution.
📤 Output (Result)
The minimum-cost path between start and goal.
💾 State
Two priority queues, two cost tables, two visited sets.
💰 Path Cost
Optimal for non-negative costs. Time/Space: O(b^(C*/2ε)).
CompleteOptimalSpace O(b^(d/2))Symmetric graphs

Informed Search

Heuristic search — uses domain knowledge h(n) to estimate distance to goal

12
algorithms
08
Greedy Best-First — Greedy Best-First Search
›
📥 Input
Initial state, goal test, successor function, heuristic h(n)
⚙️ Process (Actions)
Always expand the node with smallest h(n). Ignores g(n). Uses priority queue ordered by h(n). May revisit states.
📤 Output (Result)
A path to goal if found, but NOT guaranteed optimal. Can get stuck in local minima.
💾 State
Stores all generated nodes. Memory O(b^m) worst case.
💰 Path Cost
NOT optimal. Time: O(b^m), Space: O(b^m). Fast with good heuristic but may find very poor paths.
Not CompleteNot OptimalFast with good hLocal minima risk
09
A* — A-Star Search
›
📥 Input
Initial state, goal test, successor function, admissible heuristic h(n) where h(n) ≤ h*(n)
⚙️ Process (Actions)
Expand node with lowest f(n)=g(n)+h(n). g(n)=actual cost from start; h(n)=estimated cost to goal. Priority queue (OPEN). Expanded nodes go to CLOSED.
📤 Output (Result)
The optimal (minimum cost) path to goal. Guaranteed with admissible h(n).
💾 State
OPEN: frontier with f-values. CLOSED: expanded nodes. Stores all generated nodes.
💰 Path Cost
Optimal with admissible h. Time: O(b^d), Space: O(b^d). f(n)=g(n)+h(n).
CompleteOptimalh must be admissibleGold standard
10
IDA* — Iterative Deepening A-Star
›
📥 Input
Initial state, goal test, successor function, admissible heuristic h(n)
⚙️ Process (Actions)
DFS with f-cost threshold. Start threshold=h(start). If f(n)>threshold, prune. On failure, set new threshold=min pruned f. Repeat.
📤 Output (Result)
Optimal solution (same quality as A*) using only O(bd) memory.
💾 State
Stores only current path. Regenerates nodes across iterations. Space: O(bd).
💰 Path Cost
Optimal with admissible h. Time: O(b^d), Space: O(bd). Ideal for memory-constrained systems.
CompleteOptimalSpace O(bd)Memory efficient
11
RBFS — Recursive Best-First Search
›
📥 Input
Initial state, goal test, successor function, admissible heuristic h(n)
⚙️ Process (Actions)
Recursive DFS tracking best f-value alternative at each level. When current branch exceeds alternative, backtrack and update f-value.
📤 Output (Result)
Optimal solution with O(bd) memory. Often more efficient than IDA*.
💾 State
Current path and best f of alternatives at each node. Space: O(bd).
💰 Path Cost
Optimal. Time: potentially exponential but often better than IDA*. Space: O(bd).
CompleteOptimalSpace O(bd)Tracks alternatives
12
SMA* — Simplified Memory-Bounded A-Star
›
📥 Input
Initial state, goal test, heuristic h(n), memory limit M nodes
⚙️ Process (Actions)
A* using all available memory. When full, drop node with highest f-value. Store its f in parent for potential regeneration.
📤 Output (Result)
Best solution within memory limit M. Optimal if memory allows.
💾 State
Exactly M nodes at any time. Discards worst while remembering costs.
💰 Path Cost
Optimal if M ≥ solution path. Time varies; Space: O(M).
Complete*Optimal*Bounded memoryRegenerates dropped
13
Weighted A* — Weighted A-Star
›
📥 Input
Initial state, goal test, heuristic h(n), weight w > 1
⚙️ Process (Actions)
A* with inflated heuristic: f(n)=g(n)+w·h(n). Higher w → faster but worse quality. Finds ε-suboptimal solution where cost ≤ w·C*.
📤 Output (Result)
A path with cost ≤ w·C*. Faster than standard A*.
💾 State
Same as A* with biased f-values. Priority queue by g(n)+w·h(n).
💰 Path Cost
w-suboptimal. Trade-off: speed vs solution quality. Space: O(b^d).
Completew-suboptimalFaster than A*ε-optimal
14
Anytime A* — Anytime A-Star
›
📥 Input
Initial state, goal test, heuristic h(n), time budget
⚙️ Process (Actions)
Find initial suboptimal solution quickly (high w), then iteratively improve by reducing w. Returns best found when time runs out.
📤 Output (Result)
Best solution found within time limit. Quality improves continuously.
💾 State
Current best solution and bound. Re-uses previous search trees.
💰 Path Cost
Returns ε-optimal at any time. Improves toward optimal.
CompleteAnytimeImproves over timeTime-bounded
15
ARA* — Anytime Repairing A-Star
›
📥 Input
Initial state, goal test, heuristic h(n), initial weight w₀
⚙️ Process (Actions)
Start with large w (fast suboptimal). Repair by reducing w incrementally. Reuses previously computed information.
📤 Output (Result)
Sequence of improving solutions, converging toward optimal.
💾 State
Maintains INCONS set for efficient repair. Reuses CLOSED list.
💰 Path Cost
ε-suboptimal at each stage, decreasing ε. Space: O(b^d).
CompleteAnytimeRepair-basedε decreasing
16
D* — Dynamic A-Star
›
📥 Input
Current position, goal state, map (may change), heuristic h(n)
⚙️ Process (Actions)
Plan path backward from goal using A*. When map changes, update affected nodes via change propagation. Replan from current position.
📤 Output (Result)
Optimal path in current known map, updated efficiently as environment changes.
💾 State
OPEN and CLOSED lists. Back-pointers and cost tables for replanning.
💰 Path Cost
Optimal in current map. Efficient replanning: only affected nodes updated.
CompleteOptimalDynamic replanningBackward planning
17
D* Lite — D-Star Lite
›
📥 Input
Current position, goal, dynamic map, heuristic h(n)
⚙️ Process (Actions)
Simplified D*. Plans from goal backward using LPA*. Updates only affected nodes when environment changes.
📤 Output (Result)
Optimal path given current map. Continuously updated as obstacles detected.
💾 State
Priority queue with keys based on g-values and rhs-values (one-step lookahead).
💰 Path Cost
Optimal in current map. More efficient than D*. Used in DARPA Urban Challenge.
CompleteOptimalSimplified D*Robotics standard
18
Theta* — Theta-Star
›
📥 Input
Grid map, initial state, goal state, line-of-sight check function
⚙️ Process (Actions)
A* variant allowing paths with arbitrary angles. When expanding node n, check if grandparent has line-of-sight to child. If yes, bypass n.
📤 Output (Result)
Any-angle path: smoother and shorter than A* on grids.
💾 State
Same as A*. Additional line-of-sight checks per expansion.
💰 Path Cost
Optimal any-angle paths. More natural-looking paths in grid environments.
CompleteOptimal (any-angle)Smooth pathsGrid maps
19
JPS — Jump Point Search
›
📥 Input
Uniform-cost grid map, initial state, goal state
⚙️ Process (Actions)
A* optimization for uniform grids. Identify "jump points" — nodes that cannot be optimally reached without considering. Skip intermediate nodes entirely.
📤 Output (Result)
Same optimal path as A* but found much faster. Dramatically fewer nodes expanded.
💾 State
Same as A* with far fewer nodes expanded. Uses directional pruning rules.
💰 Path Cost
Identical optimal cost to A*. Up to 10× faster on uniform grids.
CompleteOptimalUp to 10× fasterUniform grids only

Local Search

algorithms
20
Hill Climbing — Hill Climbing Search
›
📥 Input
Initial complete state, objective function f(state), neighbor function
⚙️ Process (Actions)
Evaluate all neighbors of current state. Move to neighbor with highest f value. Repeat until no neighbor improves.
📤 Output (Result)
A local optimum — may or may not be global optimum. Returns state, not path.
💾 State
Only the current state. Space: O(1). No history maintained.
💰 Path Cost
No path cost tracked. Minimizes/maximizes objective. Stops at local optima and plateaus.
Not CompleteNot OptimalSpace O(1)Local optima risk
21
Steepest Ascent HC — Steepest Ascent Hill Climbing
›
📥 Input
Initial complete state, objective function f(state), neighbor function
⚙️ Process (Actions)
Evaluate ALL neighbors. Select neighbor with maximum improvement (steepest gradient). Move there. Repeat until no improvement.
📤 Output (Result)
A local optimum with guaranteed improvement at each step.
💾 State
Current state only. Evaluates full neighbor set before moving.
💰 Path Cost
No path cost. More computation per step than basic HC but fewer total steps.
Not CompleteNot OptimalExhaustive neighborsGradient ascent
22
Stochastic HC — Stochastic Hill Climbing
›
📥 Input
Initial complete state, objective function, neighbor function, probability distribution
⚙️ Process (Actions)
Randomly select one improving neighbor (not necessarily best). Move with probability proportional to improvement.
📤 Output (Result)
A local optimum via randomized improvement steps.
💾 State
Current state only. Space: O(1).
💰 Path Cost
No path cost. Faster per iteration than Steepest Ascent.
Not CompleteNot OptimalRandomizedFaster per step
23
Random-Restart HC — Random-Restart Hill Climbing
›
📥 Input
State generator, objective function, neighbor function, restart budget k
⚙️ Process (Actions)
Run Hill Climbing from k random initial states. Keep best solution found across all runs.
📤 Output (Result)
Best local optimum found across all k restarts.
💾 State
Current state per run. Space: O(1) per run. Best solution stored.
💰 Path Cost
No path cost. Time: O(k · HC_time). Trivially parallelizable.
Complete (prob.)Not OptimalMulti-startParallelizable

Simulated Annealing — Simulated Annealing
›
📥 Input
Initial state, objective function, neighbor function, temperature schedule T(t)
⚙️ Process (Actions)
At temperature T: pick random neighbor. If improvement: accept. If worse: accept with probability e^(ΔE/T). Gradually decrease T.
📤 Output (Result)
Near-global optimum. Probabilistically escapes local optima.
💾 State
Current state and temperature T. Space: O(1).
💰 Path Cost
No explicit path cost. Optimization of energy function E(state). Time: O(n·T_steps).
Complete (prob.)Optimal asymptoticallyEscapes local optimaTemperature schedule

Tabu Search — Tabu Search
›
📥 Input
Initial state, objective function, neighbor function, tabu list size k
⚙️ Process (Actions)
Maintain a tabu list of recently visited moves. Forbid tabu moves. Accept best non-tabu neighbor even if worse than current.
📤 Output (Result)
High-quality solution, often near-optimal. Avoids cycling through tabu mechanism.
💾 State
Current state + tabu list of recent moves (size k). Space: O(k).
💰 Path Cost
No path cost. Quality improves with iterations. Used for TSP, scheduling.
Not CompleteNot OptimalTabu listAvoids cycling

LRTA* — Learning Real-Time A-Star
›
📥 Input
Current agent position, goal, heuristic h(n), partially known map
⚙️ Process (Actions)
Look ahead k steps with A*, execute one move. Update h(s) ← max(h(s), c(s,a)+h(s')). Learn better heuristics over time.
📤 Output (Result)
Reaches goal eventually. Heuristic values improve with experience.
💾 State
Current state + updated heuristic table H. Space: O(|S|).
💰 Path Cost
Path cost tracked. Converges to optimal paths as heuristics improve.
CompleteNot OptimalLearns heuristicsReal-time

RTA* — Real-Time A-Star
›
📥 Input
Current agent position, goal state, heuristic h(n)
⚙️ Process (Actions)
Run A* for exactly k steps from current position. Move agent one step. Update heuristic. Repeat.
📤 Output (Result)
Reaches goal with updated heuristics. Bounded deliberation per step.
💾 State
Current state + heuristic table. One-step update per move.
💰 Path Cost
Path cost tracked. k steps lookahead per action. Space: O(k).
CompleteNot Optimalk-step lookaheadBounded deliberation

Genetic Algorithms — Genetic Algorithms (GA)
›
📥 Input
Population of encoded solutions (chromosomes), fitness function, crossover/mutation operators
⚙️ Process (Actions)
1) Evaluate fitness. 2) Select parents (tournament/roulette). 3) Crossover: combine chromosomes. 4) Mutation: random changes. 5) Replace population. Repeat for N generations.
📤 Output (Result)
Best individual across all generations. Approximation to global optimum.
💾 State
Population of k individuals (chromosomes). Each = complete solution encoding.
💰 Path Cost
No path cost. Maximizes/minimizes fitness. Time: O(generations · population · eval).
Not CompleteNot OptimalPopulationSelection + Crossover + Mutation
29
Genetic Programming — Genetic Programming (GP)
›
📥 Input
Population of programs (parse trees), fitness function, function/terminal sets
⚙️ Process (Actions)
Same as GA but individuals are program trees. Crossover: swap subtrees. Mutation: replace subtree with random program. Evolves code automatically.
📤 Output (Result)
A program (function) that solves the task according to fitness.
💾 State
Population of parse trees of varying sizes and shapes.
💰 Path Cost
No path cost. Fitness measures program correctness/efficiency. Computationally expensive.
Not CompleteNot OptimalEvolves codeTree representation

Population of real-valued vectors, fitness function, strategy parameters σ
⚙️ Process (Actions)
Mutate individuals by adding Gaussian noise N(0,σ²). Select best offspring. Self-adapt σ: if success rate > target, increase; else decrease.
📤 Output (Result)
Near-optimal real-valued solution vector.
💾 State
Population of (solution, σ) pairs. Strategy parameters co-evolve.
💰 Path Cost
No path cost. Self-adapting mutation strength. Time: O(generations · pop · eval).
Not CompleteNot OptimalReal-valuedSelf-adaptive σ

📥 Input

Scout bees randomly explore. Best sites identified. Recruit forager bees to elite sites for local exploitation. Others continue global exploration.
📤 Output (Result)
Near-optimal solution through balance of global exploration and local exploitation.
💾 State
Set of sites (solutions) with quality scores. Bees assigned per site.

Firefly Algorithm — Firefly Algorithm (FA)
›
📥 Input
Population of fireflies (solutions), light intensity function I(x), absorption γ
⚙️ Process (Actions)
Less bright firefly moves toward brighter: x_i←x_i+β₀·e^(−γ·r²)·(x_j−x_i)+α·ε. Brightness = fitness.
📤 Output (Result)
Near-optimal solution. Brightest firefly = best solution.
💾 State
Population of positions. Attractiveness decreases with distance squared.
💰 Path Cost
No path cost. Light intensity = objective. Handles multimodal landscapes. O(n²·it·eval).

MCTS — Monte Carlo Tree Search
›
📥 Input
Game/problem state, action set, simulation policy, computational budget
⚙️ Process (Actions)
4 phases: 1) Selection: traverse tree with UCB1. 2) Expansion: add new child. 3) Simulation: random rollout. 4) Backpropagation: update W/N counts up tree.
📤 Output (Result)
Best action from root based on simulation statistics.
💾 State
Search tree with nodes (visit_count N, win_count W). Grows with budget.
💰 Path Cost
UCB1: a=argmax[W/N+C·√(ln(N_parent)/N)]. Time: O(budget). Quality improves with simulations.
Not CompleteNot Optimal guaranteed4-phase loopBudget-based
37
UCT — Upper Confidence Bound for Trees
›
📥 Input
Game state, action set, exploration constant C, simulation budget
⚙️ Process (Actions)
MCTS where selection uses UCB1: UCB1(node)=W/N+C·√(ln(N_parent)/N). C balances exploration vs exploitation.
📤 Output (Result)
Action with highest UCB1-guided value after budget exhausted.
💾 State
Tree nodes with (W,N) statistics. C parameter controls exploration.
💰 Path Cost
UCB1 provides theoretical exploration guarantee. Foundation of AlphaGo. O(budget).
Not CompleteUCB1 selectionExploration-exploitationAlphaGo foundation

📤 Output (Result)
Solution found within k-wide beam. NOT guaranteed optimal.
💾 State
Stores exactly k nodes at current level. Memory: O(k·b) per level.
💰 Path Cost
Minimizes scoring function, not guaranteed path cost optimality. Time: O(k·b·d).
Not CompleteNot Optimalk nodes per levelNLP / LLMs

Like Beam Search but select k survivors probabilistically: P(node)∝e^(score/T). T→0: greedy. T→∞: random sampling.

Solution with stochastic selection introducing diversity.
💾 State
k probabilistically-selected nodes at each level.

No path cost guarantee. More robust than deterministic beam to local optima.

›
📥 Input
AND-OR problem graph, initial state, goal conditions, action/outcome model

OR nodes: choose one action (agent's choice). AND nodes: all outcomes must be handled. Recursively solve subproblems. Prune when subtree solution found.

A conditional plan (policy) that solves the problem for ALL possible outcomes.

AND-OR tree with solution labels. OR needs one solution; AND needs all.

Backtracking Search — Backtracking Search (for CSP)
›
📥 Input
Variables {X₁…Xn}, domains {D₁…Dn}, constraints C, variable/value ordering heuristics
⚙️ Process (Actions)
Recursively assign values to unassigned variables. Check constraint consistency after each assignment. If inconsistent, backtrack. Apply MRV and degree heuristics.
📤 Output (Result)
Complete assignment satisfying all constraints, or failure.
💾 State
Partial assignment of variables. Current variable being assigned. Constraint network.
💰 Path Cost
No path cost (CSP = constraints, no costs). Time: O(d^n) worst case. Space: O(n).
CompleteN/A (no cost)MRV heuristicConstraint checking
42
Forward Checking — Forward Checking (FC)
›
📥 Input
CSP (variables, domains, constraints), partial assignment
⚙️ Process (Actions)
After assigning X=v: remove from D(Y) all values inconsistent with X=v for each unassigned Y. If D(Y) becomes empty, immediately backtrack.
📤 Output (Result)
Complete consistent assignment, or failure. Detects failures earlier than basic backtracking.
💾 State
Partial assignment + reduced domains for unassigned variables.
💰 Path Cost
No path cost. Reduces search space via propagation. Space: O(n·d).
CompleteN/A (no cost)Constraint propagationEarly failure detection
43
AC-3 — Arc Consistency Algorithm 3
›
📥 Input
Constraint network (variables, domains, binary constraints), queue of arcs (Xi,Xj)
⚙️ Process (Actions)
For each arc (Xi,Xj): remove values from Di with no support in Dj. If Di changed, re-add arcs (Xk,Xi) to queue. Repeat until queue empty.
📤 Output (Result)
Arc-consistent network with reduced domains, or failure if domain becomes empty.
💾 State
Domain sets for each variable + queue of arcs.
💰 Path Cost
No path cost. Preprocessing to reduce domains. Time: O(ed³), Space: O(e).
CompleteN/A (no cost)O(ed³) timePreprocessing

Min-Conflicts — Min-Conflicts Heuristic
›
📥 Input
Initial complete assignment (possibly inconsistent), constraint set, max iterations
